# Priscilla Diogo · Advocacia Trabalhista

Site estático (HTML/CSS/JS), sem etapa de build.

- `index.html` — site principal
- `links.html` — página "link na bio" do Instagram (`/links`)
- `img/`, `video/` — fotos e vídeos otimizados
- `fonts/` — Cormorant Garamond e Manrope (self-hosted)
- `vendor/` — GSAP 3.12.5, ScrollTrigger e Lenis 1.1.13

## Deploy na Vercel
Importar o repositório → Framework Preset: **Other** → sem build command → Output: raiz (`.`).
